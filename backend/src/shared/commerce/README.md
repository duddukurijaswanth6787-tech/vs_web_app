# Commerce Shared Module

Shared enums, constants, interfaces, types, and utilities for the Commerce Layer.

## Enums
ProductStatus, ProductVisibility, InventoryStatus, StockMovementType, MediaType, AttributeType, PriceType, DiscountType, VariantStatus, WarehouseStatus

## Utilities
SkuGenerator, SlugGenerator, BarcodeGenerator, PriceFormatter, WeightFormatter, DimensionFormatter

## Constants
Pagination limits, image/video/file size limits, stock thresholds, SKU/barcode config, precision values.
