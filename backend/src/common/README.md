# Common Folder

Contains shared, reusable components that are stateless and domain-agnostic.

## Folder Contents
- **filters/**: Exception filter mappings (e.g. `GlobalExceptionFilter`)
- **interceptors/**: Response parsing logic (e.g. `GlobalResponseInterceptor`)
- **logger/**: Pino logger module configuration
- **guards/**: Custom route guards
- **decorators/**: Custom NestJS decorators
- **pipes/**: Custom pipes and parsers
- **middleware/**: HTTP middlewares
- **utils/**: General utilities
- **interfaces/**: Standard interfaces
- **constants/**: System constants
- **types/**: TS type declarations
