# Frontend Directory

Placeholder workspace for the e-commerce client interface. Built using Next.js.

## Folder Structure
- **src/app/**: App router layout pages separated into:
  - `(customer)/`: Shopping catalog pages
  - `admin/`: Site administration panels
  - `staff/`: Warehouse management portals
  - `(auth)/`: Login and verification flows
- **src/shared/**: Reusable styles, states, types, services, layouts, hooks, and helpers.
- **public/**: Client visual assets.
